For plugin and platform teams

See your plugin in a real IDE.

We start a real JetBrains IDE in a container, install your plugin, and let an AI agent work through your scenarios, the way your users and their agents will. Every run leaves a video, screenshots, logs, and a report.

How the test harness works.

A real IDE in a container

Linux, a virtual display, and the IDE itself. We configure it through typed IntelliJ APIs, import the project, and wait until indexing is done.

Driven by a real agent

Claude Code, Codex, or Gemini runs your task against the running IDE. Nothing is mocked, so you see what an agent actually does with your plugin.

Every run is recorded

A screen video, screenshots, the agent’s tool calls, and the IDE logs. If the IDE hangs on a dialog, we take a thread dump before stopping it.

12 IDE products

IntelliJ IDEA, PyCharm, GoLand, WebStorm, Rider, CLion, PhpStorm, RubyMine, RustRover, DataGrip, MPS, and Android Studio.

Several IDE versions

Build your plugin once, then run the same binary on newer releases and EAP builds, with Plugin Verifier on top.

Measured, not narrated

The report is computed from the run data, never written by an agent. Failures stay in it.

Linux containers by default. macOS and Windows runs on request.
