Try it with devrig.

The current release uses the devrig command and the MCP Steroid plugin.

curl -fsSL https://devrig.dev/install.sh | sh
irm https://devrig.dev/install.ps1 | iex

Then run devrig install codex, or use claude or gemini. Read the setup guide ↗

What your agent can do.

Find the right symbol

Resolve declarations and follow their references across modules using the IDE’s project model.

Change code structurally

Run typed refactors and use IDE inspections to check the result.

Check it by running it

Use the IDE’s debugger and run configurations to investigate behavior and execute tests.
